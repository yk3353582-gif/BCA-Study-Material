5. Check Prime Number

Check whether a given number is a prime number.

num = 29
is_prime = num > 1
i = 2
while i * i <= num:
    if num % i == 0:
        is_prime = False
        break
    i += 1
print(num, "is prime" if is_prime else "is not prime")

7. Factorial Using Recursion

Find the factorial of a number using recursion.

def factorial(n):
    if n == 0:
        return 1
    return n * factorial(n - 1)

print("Factorial of 5 =", factorial(5))

15. Armstrong Number Check

Check whether a number is an Armstrong number.

num = 153
original = num
total = 0
while num != 0:
    digit = num % 10
    total += digit ** 3
    num //= 10
print(original, "is an Armstrong number" if original == total else "is not an Armstrong number")

17. LCM of Two Numbers

Find the least common multiple of two numbers.

a, b = 4, 6
gcd = 1
for i in range(1, min(a, b) + 1):
    if a % i == 0 and b % i == 0:
        gcd = i
lcm = (a * b) // gcd
print("LCM =", lcm)

22. Linear Search

Search for an element in an array using linear search.

arr = [10, 25, 30, 45, 60]
target = 45
index = -1
for i, num in enumerate(arr):
    if num == target:
        index = i
        break
print("Found at index", index if index != -1 else "Not found")

23. Binary Search

Search for an element in a sorted array using binary search.

arr = [10, 25, 30, 45, 60]
target = 45
low, high, result = 0, len(arr) - 1, -1
while low <= high:
    mid = (low + high) // 2
    if arr[mid] == target:
        result = mid
        break
    elif arr[mid] < target:
        low = mid + 1
    else:
        high = mid - 1
print("Found at index", result if result != -1 else "Not found")

24. Bubble Sort

Sort an array using the bubble sort algorithm.

arr = [5, 2, 9, 1, 5, 6]
n = len(arr)
for i in range(n - 1):
    for j in range(n - 1 - i):
        if arr[j] > arr[j + 1]:
            arr[j], arr[j + 1] = arr[j + 1], arr[j]
print(arr)

25. Selection Sort

Sort an array using the selection sort algorithm.

arr = [29, 10, 14, 37, 13]
n = len(arr)
for i in range(n - 1):
    min_index = i
    for j in range(i + 1, n):
        if arr[j] < arr[min_index]:
            min_index = j
    arr[i], arr[min_index] = arr[min_index], arr[i]
print(arr)
